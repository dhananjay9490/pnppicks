PnP Picks Uploader – Architecture

Single-user internal tool. Runs as a Windows scheduled task (every 30 min; builds a Short only at the configured slots, currently 12:30 and 19:00 IST) on the channel owner's PC. Google Cloud project: lumen-media · API client: pnp-picks-uploader
Data flow (left to right)
Public deal postsOur own Telegram channels (t.me/s/… public preview). Title, price, % off, product photo.
→
pick.jsSelect 1 or 3 of today's deals (never the same deal twice in 3 days)
→
script.jsHinglish voice-over text, title, description, affiliate disclosure
→
tts.jsText-to-speech (edge-tts, neural voice) → vo.mp3 + subtitles
→
render.jsffmpeg → 1080×1920 MP4, 15–40 s
YouTube Data API v3videos.insert (resumable upload) · channels.list (own channel only)
←
upload.jsOAuth 2.0 (refresh token stored locally) · scopes: youtube.upload, youtube.readonly
←
out/YYYY-MM-DD/short.mp4 · script.json · uploaded.json (prevents duplicate uploads)
Quota: 2 videos.insert/day (3,200 units) today, hard-capped in code at 6/day (9,600 units); target 10/day (16,000 units) is why we request a 20,000-unit quota. Data handling: only our own channel's data; no third-party user data is accessed, stored or shared; credentials never leave the owner's PC.
