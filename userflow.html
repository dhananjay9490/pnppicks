PnP Picks Uploader – User Flow

The only "user" is the channel owner. Viewers never interact with the API client; they only watch the published videos on YouTube.

A. One-time setup (channel owner, once)

1. Run node upload.js authTool prints a Google OAuth consent URL
→
2. Google consent screenOwner signs in with the PnP Picks brand account and clicks Allow (scopes: youtube.upload, youtube.readonly)
→
3. Token stored locallyRefresh token saved in a gitignored .env on the owner's PC. Revocable any time in Google Account permissions.

B. Automatic run per slot (Windows Task Scheduler, every 30 min; slots 12:30 and 19:00 IST)

1. Pick dealsRead today's posts from our own public Telegram channels; choose 1 or 3 (no repeats within 3 days)
→
2. Build videoVoice-over + text cards + product photo → short.mp4 (1080×1920, 15–40 s)
→
3. videos.insertUpload to our own channel: title, description (deals, Telegram links, affiliate disclosure), notForKids, privacy = private, publishAt = slot time
→
4. Record resultVideo ID written to uploaded.json so the same slot is never uploaded twice; quota.json caps API uploads at 6/day
→
5. Public at slot timeYouTube publishes the scheduled Short; viewers watch it normally on YouTube

C. Owner review (optional, daily)

Check YouTube StudioOwner can edit title/description or delete the video like any manually uploaded video. No other API calls are made.
